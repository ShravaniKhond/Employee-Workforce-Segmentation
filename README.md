# Employee Workforce Segmentation

## Project Overview
Employee Workforce Segmentation is a Machine Learning project that groups employees based on similarities in their numerical data.

This project uses K-Means Clustering, Hierarchical Clustering, and Principal Component Analysis (PCA) to identify employee groups and visualize the results.

## Objectives
- Apply K-Means clustering to employee data.
- Implement Hierarchical Clustering.
- Reduce feature dimensions using PCA.
- Visualize employee clusters in two dimensions.
- Compare clustering models using the Silhouette Score.

## Dataset
**Dataset Name:** IBM HR Analytics Employee Attrition

- Records: 1,470
- Original columns: 35
- Input: Numerical employee features
- Employee identifiers and the Attrition target are excluded from the clustering inputs.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- SciPy

## Algorithms Implemented

### 1. K-Means Clustering
K-Means groups employees into three clusters based on similarities in their numerical features.

### 2. Hierarchical Clustering
Hierarchical Clustering groups employees by analyzing similarities between data points and their hierarchical relationships.

### 3. Principal Component Analysis (PCA)
PCA reduces the standardized numerical features to two principal components for visualization.

## Evaluation
The Silhouette Score is used to evaluate how well-separated the clusters are. The script also reports the explained variance of the two PCA components.

Actual scores should be taken from the output generated by running the Python script.

## Installation
Install the required Python libraries:

```bash
python -m pip install pandas numpy matplotlib seaborn scikit-learn scipy
```

## How to Run
Run the following command from the project root directory:

```bash
python src/workforce_segmentation.py
```

The generated files will be saved in the `outputs` folder.

## Conclusion
This project demonstrates how clustering algorithms can group employee records and how PCA can help visualize the resulting groups. These groups are exploratory patterns, not definitive employee categories or proof of individual behavior.

## Future Scope

## Responsible Use
Employee information should be handled carefully. Clustering results should support aggregate analysis and should not be used as the sole basis for consequential employment decisions.
